# Controles (remapeáveis em Opções)

| Ação | Teclado / mouse |
|---|---|
| Mover (8 direções) | WASD ou setas |
| Ataque (combo de 3; segure e solte para ataque carregado, 20 de vigor) | J ou botão esquerdo |
| Defesa frontal (segurar) | K ou botão direito |
| Esquiva (rolamento) | Espaço |
| Interagir / falar / confirmar | E |
| Habilidade da criatura (na direção atual) | Q |
| Trocar criatura ativa (recarga de 6 s) | Tab |
| Comportamento da criatura (Acompanhar, Atacar alvo, Proteger, Preservar) | C |
| Captura: 1º F mira, 2º F lança o Selo; Tab troca de alvo; K cancela | F |
| Ecos (Raiz Viva após o Cervo) | 1 e 2 |
| Tônico | R |
| Equipe / menu | I |
| Pausa | Esc |

## Guia rápido
- Capture: aperte F para mirar (mostra alcance e a chance em %) e F de novo para lançar. Pode tentar com qualquer vida; quanto menos vida, maior a chance (barra laranja = ponto ideal, ≤ 35%). O vínculo canaliza por 1,2 s; se você for atingido, ele é interrompido.
- Ataques inimigos são anunciados com um "!" e um aviso listrado no chão. Esquive (Espaço) no fim do aviso.
- Santuários (cristal azul) curam a equipe, gravam o ponto de retorno e salvam o jogo.
- Sentinelas defendem pela frente: ataque pelos lados ou use o Avanço do Cascalito.
- O Cervo de Ossos tropeça nos pilares e expõe o núcleo. Fique atrás de um pilar quando ele raspar o chão.
