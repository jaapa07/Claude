JsonToXmlTemplate: monta XML a partir de JSON com um template

Escreva o XML de saída do jeito que ele precisa ficar e marque onde entram os dados do JSON. A parte única funciona como um ReplaceText: {{campo}} é trocado pelo valor. As listas são repetidas com {{#each lista}} ... {{/each}}. O documento sai completo ou vai para failure, nunca pela metade, e não precisa de SplitJson + MergeContent.

Exemplo

JSON de entrada:

{"numero": 123, "cliente": {"nome": "Silva & Filhos", "cnpj": "12345678000199"},
 "itens": [{"sku": "A1", "qtd": 2}, {"sku": "B7", "qtd": 1}]}

Template:

<Pedido numero="{{numero}}">
  <Cliente cnpj="{{cliente.cnpj}}">{{cliente.nome}}</Cliente>
  <Itens total="{{itens.length}}">
    {{#each itens}}
    <Item seq="{{@number}}"><Sku>{{sku}}</Sku><Qtd>{{qtd}}</Qtd></Item>
    {{/each}}
  </Itens>
</Pedido>

XML gerado:

<Pedido numero="123">
  <Cliente cnpj="12345678000199">Silva &amp; Filhos</Cliente>
  <Itens total="2">
    <Item seq="1"><Sku>A1</Sku><Qtd>2</Qtd></Item>
    <Item seq="2"><Sku>B7</Sku><Qtd>1</Qtd></Item>
  </Itens>
</Pedido>

Marcações

MarcaçãoO que faz
{{campo}}, {{a.b.c}}, {{lista[0].x}}Valor do JSON, já escapado para XML
{{lista.length}}Quantidade de itens da lista
{{{campo}}}Valor sem escape (para inserir um trecho de XML pronto)
{{#each lista}} ... {{/each}}Repete o trecho para cada item. {{else}} é usado quando a lista está vazia
{{this}}O item atual (lista de textos simples)
{{@number}}, {{@index}}, {{@count}}, {{@first}}, {{@last}}Posição no laço (1, 2, 3... / 0, 1, 2... / total / primeiro / último)
{{#if campo}}, {{#if valor > 0}}, {{#if status == 'A'}}Condição, com {{else}} opcional. Operadores: == != > < >= <=
{{#unless campo}}Condição negada
{{#with cliente}} {{nome}} {{/with}}Entra num objeto para não repetir o caminho
{{../campo}}, {{@root.campo}}Campo do nível de cima / da raiz do JSON
{{@attr.filename}}Atributo do FlowFile
{{! comentário }}Comentário, não aparece no XML

Dentro de uma lista, se um campo não existir no item, ele é procurado nos níveis de cima. Assim, {{numero}} do pedido pode ser usado dentro de cada item.

Filtros

FiltroExemploResultado
default{{obs | default:'N/A'}}N/A quando vazio ou ausente
upper / lower / trim{{nome | trim | upper}}ANA SILVA
number{{valor | number:2}}1520.75 (aceita "1.234,56")
date{{emissao | date:'dd/MM/yyyy'}}02/11/2026 (entrada ISO, dd/MM/yyyy, yyyyMMdd...)
date com entrada{{d | date:'yyyy-MM-dd':'ddMMyyyy'}}formato de saída : formato de entrada
digits{{cnpj | digits}}12345678000199
lpad / rpad{{numero | lpad:9}}000004521
truncate{{obs | truncate:60}}primeiros 60 caracteres
replace{{x | replace:';':','}}troca texto
json{{objeto | json}}o valor como texto JSON

Dicas

  • Linhas que só têm {{#each}}, {{/each}}, {{#if}} etc. não geram linha em branco no XML.
  • Se o JSON trouxer um objeto onde o template espera uma lista (comum quando o JSON veio de um XML), ele é tratado como lista de um item.
  • Use Arquivo de template com Expression Language para escolher o template pelo tipo de documento: /opt/nifi/templates/${tipo}.xml. O arquivo é relido automaticamente quando muda.
  • Se o JSON puder chegar quebrado, coloque o RepairXmlJson antes.
  • Números do JSON saem exatamente como vieram. Use number:2 para fixar casas decimais.
